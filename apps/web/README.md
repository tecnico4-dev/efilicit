# Frontend web (`@efilicit/web`)

Next.js + React + TypeScript + Tailwind CSS.

## Desarrollo

Desde la raíz del monorepo:

```powershell
pnpm install
pnpm dev
```

Abre http://localhost:3000

Variables locales: copia `.env.example` a `.env.local` (valores de Supabase **local**, nunca producción en desarrollo).
